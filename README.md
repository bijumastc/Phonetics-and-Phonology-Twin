# Phonetics and Phonology Twin

Interactive practice tool for English Phonetics & Phonology (RP).

- 3 sets of 25 questions (75 total)
- 2-mark, 5-mark and 10-mark questions
- Immediate feedback + Learning Twin
- Optional Google Sheet for teacher dashboard

## How students use it
1. Open the link
2. Enter name, roll number and college
3. Practise the sets

## For teachers
- Add your Google Apps Script URL at the top of `index.html` to collect scores
